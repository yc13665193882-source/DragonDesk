# DragonDesk 龙娘游戏展台

DragonDesk 是一款 Windows 11 x64 桌宠。点龙娘可以打开展台、启动游戏或翻看上次留下的便签。可以切换常规龙娘和抱膝盘尾的 Q 版龙娘。贴在左、右或底边时，她会先停留展示，再收回到探头姿态，鼠标移过去就会走出来。贴在顶部时始终全身可见。

DragonDesk 免费，无需注册。游戏库、便签和外观设置保存在当前 Windows 用户的电脑上。点影音搜索或打开游戏平台时，请求由你选择的第三方服务处理。

## 安装与升级

双击 MSI 开始安装。首次安装时可以选择空文件夹作为安装位置，也可以取消默认勾选的「在桌面创建 DragonDesk 快捷方式」。阅读并接受组件条款后即可继续安装。完成页可直接打开展台，首次打开后可选择「导入游戏」或「发现本机游戏」。从 0.29.3 升级时，先右键桌宠退出，再运行新版安装包。[下载 DragonDesk 1.0.0（Windows x64）](https://github.com/yc13665193882-source/DragonDesk/releases/download/v1.0.0/DragonDesk-1.0.0-win-x64.msi) · [发行与校验说明](https://github.com/yc13665193882-source/DragonDesk/releases/tag/v1.0.0)

要卸载程序，可以在开始菜单搜索「卸载 DragonDesk」，也可以到 Windows「设置 → 应用 → 安装的应用」找到 DragonDesk，选择「卸载」。卸载后会保留游戏库和便签。「使用与隐私」说明了如何清除本机记录。如果只是想清理下载目录，可以直接删除下载的 MSI 文件。

如果曾通过命令行把 0.29.2 或更早的安装版装在其他位置，请先运行新版向导，按提示核对旧安装目录，并使用向导给出的卸载命令。普通双击安装的旧版可以直接运行新版 MSI 升级。
